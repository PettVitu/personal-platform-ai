## Decisão de produto atual

O MVP deve validar o ciclo **descobrir conteúdo → concluir uma prática → publicar projeto → receber feedback**. Monetização entra como infraestrutura simples e teste de disposição a pagar, não como marketplace completo.

## Status

Documentação end-to-end concluída para iniciar descoberta técnica e prototipação. O lançamento ainda depende das validações indicadas no documento 10.
